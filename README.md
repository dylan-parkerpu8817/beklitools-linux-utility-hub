## What is bekliTools?

bekliTools combines multiple desktop helpers for Linux systems using X11. The included utilities address a range of practical tasks: pieStatistic records time and activity, other tools provide keyboard and mouse input control, and voice features handle speech-to-text conversion and spoken commands.

The project also provides painting capabilities. Drawings can be saved as TXT data that records coordinates together with RGB color values, giving image information in a straightforward format that can be inspected or used by other workflows.

---

## Capabilities

- Measure activity and elapsed time with pieStatistic.
- Modify and manage keyboard input.
- Modify and manage mouse input.
- Turn spoken audio into text.
- Trigger actions with voice commands.
- Perform voice recognition through Vosk.
- Create images with the included drawing tools.
- Save drawings to TXT files containing coordinates and RGB values.

## Using the Utilities

Choose the component that fits the task at hand:

1. Start pieStatistic when you need to log activity or track durations.
2. Use the keyboard or mouse utility to control or edit input.
3. Turn on Vosk recognition for speech-to-text processing.
4. Select voice-command functionality when an operation should be initiated verbally.
5. Open the painting utility and create the desired image.
6. Export the drawing to TXT when coordinate and RGB data is required.
